# Редактор статей для TravmaVizV2

Редактор доступен по адресу `/admin.html`. Вход закрыт паролем из переменной окружения `ADMIN_PASSWORD`; пароль не хранится в разметке или JavaScript. В редакторе можно создать статью, сохранить её черновиком, опубликовать, изменить или удалить. Публичный сайт загружает только публикации со статусом «Опубликована».

## Локальный запуск в Windows

Нужен Node.js 20 или новее. Запустите `start-server.ps1` из папки сайта. Скрипт спросит пароль скрытым вводом и запустит сайт вместе с API редактора. Пароль должен содержать не менее 16 символов.

По умолчанию сайт слушает `127.0.0.1:8765`. Скрипт `start-server.ps1` сохраняет статьи в `%LOCALAPPDATA%\TravmaVizV2-data\articles.json`. При прямом запуске `node server.mjs` без `DATA_DIR` создаётся отдельная папка `TravmaVizV2-data` рядом с сайтом. Если порт уже занят локальным статическим сервером, перед запуском остановите его либо в PowerShell задайте другой свободный порт: `$env:PORT = '8766'`.

Для прямого запуска из терминала можно задать переменные окружения `ADMIN_PASSWORD`, `DATA_DIR`, `PORT` и `HOST`, затем выполнить `node server.mjs`. Не добавляйте пароль в файлы проекта или репозиторий. Для проверки с телефона в домашней сети можно указать `HOST=0.0.0.0` и открыть локальный IP компьютера.

## Размещение после релиза

Сайт и API должны работать на одном Node.js сервере. Обычный статический хостинг и команда `python -m http.server` не могут сохранять публикации. Для продакшена нужен хостинг, который поддерживает Node.js, HTTPS и постоянный диск/том. Настройте:

- `ADMIN_PASSWORD` — длинный уникальный пароль (от 16 символов);
- `DATA_DIR` — путь к постоянному хранилищу, расположенный вне публичной папки сайта;
- `PORT` — порт, который передаёт хостинг;
- `NODE_ENV=production` — включает флаг `Secure` у сессионной cookie; сайт должен открываться по HTTPS.

Хранилище здесь — JSON-файл на диске сервера. Оно подходит для небольшой редакции с одним экземпляром сервера. При нескольких экземплярах приложения или хостинге без постоянного диска понадобится подключить общую базу данных. Перед обновлением сайта делайте резервную копию `articles.json`; папка данных не должна попадать в публичную раздачу.

Сессия администратора действует 8 часов и хранится в памяти сервера; после его перезапуска нужно войти снова. Тексты статей сохраняются как обычный текст, абзацы разделяются пустой строкой. HTML не исполняется.
